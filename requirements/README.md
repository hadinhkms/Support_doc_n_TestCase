# Requirements

Mỗi requirement là một page Markdown độc lập theo `templates/requirement-template.md`.

Quy ước ID: `REQ-<3 chữ số>`; acceptance criterion: `AC-<3 chữ số>`. Không sửa ID sau khi đã được dùng trong test case hoặc script; nếu requirement thay đổi lớn, tăng version và ghi change log.

Xem `REQ-001-sign-in.md` làm ví dụ mẫu đầy đủ: acceptance criteria dạng Given/When/Then, bảng rules/validation, open questions có owner và hạn, bảng evidence/confidence, gap phát hiện từ automation và change log.
